# Superstore Sales Analysis Dashboard

##  Project Overview

This project analyzes the Sample Superstore dataset using **Microsoft Excel and Power BI**. The data was cleaned and validated in Excel and then used to create an interactive Power BI dashboard to understand sales performance across regions, categories, and sub-categories.

##  Objective

- Clean and preprocess the Superstore dataset.
- Analyze overall sales, profit, and quantity.
- Compare sales performance across different regions.
- Analyze sales by product categories and sub-categories.
- Create an interactive Power BI dashboard for easy analysis.

##  Tools Used

- Microsoft Excel
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

##  Excel Data Cleaning

The dataset was cleaned and prepared in Microsoft Excel before importing it into Power BI.

### Cleaning Steps

- Checked for missing values.
- Identified and removed duplicate records.
- Verified numerical data types for Sales, Quantity, Discount, and Profit.
- Checked consistency of Segment, Region, Category, and Sub-Category fields.
- Validated the cleaned dataset for Power BI analysis.

### Dataset Summary

- Original Records: 9,994
- Duplicate Records Removed: 17
- Final Unique Records: 9,977
- Missing Values: None

##  Power BI Dashboard

The interactive dashboard provides the following key metrics and visualizations:

### Key Performance Indicators

- **Total Sales:** 2.30M
- **Total Profit:** 286.40K
- **Total Quantity:** 37,873

### Dashboard Visuals

1. **Sales by Region**
   - Compares sales performance across Central, East, South, and West regions.

2. **Sales by Category**
   - Shows sales distribution across Furniture, Office Supplies, and Technology.

3. **Top 10 Sub-Categories by Sales**
   - Highlights the sub-categories generating the highest sales.

4. **Region Slicer**
   - Allows users to filter the dashboard by region and interactively analyze the results.

##  Key Insights

- The dashboard provides a quick overview of total sales, profit, and quantity.
- Sales performance can be compared across different regions.
- Category-level analysis helps understand the contribution of Furniture, Office Supplies, and Technology.
- The Top 10 Sub-Categories visual highlights the strongest-performing sub-categories.

##  Data Limitation

The provided Sample Superstore dataset does not contain an **Order Date** or **Product Name** field. Therefore, monthly sales trends and individual product-level analysis were not created. Instead, the available **Sub-Category** field was used for detailed sales analysis.

No artificial data was added to the dataset.
